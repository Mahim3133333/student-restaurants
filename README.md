# Student Restaurants Finland

A simple web application for viewing student restaurants in Finland and their daily and weekly menus.

## Features

- Restaurant list
- Daily menu
- Weekly menu
- Filter restaurants by city
- Favorite restaurants
- Favorites saved with localStorage
- Responsive design

## Technologies

- HTML
- CSS
- Vanilla JavaScript
